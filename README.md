# Controle de Despesas Pessoais

## Objetivo Geral
Facilitar o controle de gastos diários e mensais, registrando e exibindo despesas.

## Funcionalidades Previstas
- Cadastro de despesas com valor, categoria e data.
- Cálculo e exibição do total de gastos.
- Listagem de todas as despesas.
- Opção para zerar o total.
